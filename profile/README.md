<h3>几个容易混淆的易错点提醒</h3>

<ol>
<li>"Odds"既是复数形式也是单数概念——说"a set of odds"比"an odd"更规范正式</li>
<li>"Underdog"特指实力较弱一方而非泛指任何弱势方；与之对应的是"Favorite"</li>
<li>"Bookie/Bookmaker"原义指"记录者"（记录赌局结果的人），现引申为整个博彩机构本身</li>
</ol>
